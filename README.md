# AllPetSocial

AllPetSocial is a social network for pets.

A human user owns and manages one or more pet profiles. Each pet acts as an independent social identity with its own profile, posts, followers, likes, and comments.

## Stack

- TypeScript
- Next.js
- React
- Tailwind CSS
- NestJS
- PostgreSQL
- Prisma
- JWT
- Docker
- Kubernetes
- NGINX Ingress

## Structure

- frontend/     Next.js application
- backend/      NestJS API
- kubernetes/   Kubernetes manifests
- docker/       Docker-related files
- docs/         Project documentation
